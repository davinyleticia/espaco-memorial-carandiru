1. De acordo com o documento, um sistema computacional é composto por três componentes básicos e fundamentais. Quais são esses componentes?

2. A finalidade principal de um sistema operativo pode ser sintetizada em duas palavras-chave. Quais são elas?

3. Na evolução histórica dos sistemas operativos, qual foi a inovação característica da 2ª Fase que permitiu a utilização de uma mesma máquina por múltiplos utilizadores através de terminais?

4. Na história das telecomunicações móveis, que tecnologia introduziu o módulo SIM (cartão ou chip), libertando o equipamento da linha telefónica?

5. O sistema Android foi desenvolvido utilizando o conceito de plataforma aberta. Qual é o sistema operativo (kernel) sobre o qual a arquitetura do Android é baseada?

6. Como se designa o tipo de sistema operativo em que os recursos de múltiplas máquinas são apresentados ao utilizador de forma transparente, como se fossem um único sistema centralizado?

7. Para garantir a segurança, os processadores dividem a execução em níveis de privilégio. Em qual nível operam as aplicações comuns, onde o uso de memória é restrito e instruções "perigosas" são proibidas?

8. Como se denomina a interface que uma aplicação utiliza para invocar de forma controlada os serviços disponibilizados pelo núcleo do sistema operativo?

9. Existe uma arquitetura de Sistemas Operativos na qual os componentes do núcleo operam todos num só nível e relacionam-se entre si sem restrições. Qual é o nome desta arquitetura?

10. Por que conhecer sistemas operacionais ajuda a evitar erros de programação?

11. Como a evolução histórica dos sistemas operacionais influenciou os sistemas atuais?

12. Explique a importância do gerenciamento de processos? ( Reflexivas )

13. Como o sistema operacional resolve conflitos de uso de recursos?
