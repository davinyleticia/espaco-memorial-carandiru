# 🧩 Tarefa – Programação Orientada a Objetos (POO) em Python

## 🎯 Objetivo

Desenvolver uma classe em Python utilizando os conceitos de **Programação Orientada a Objetos (POO)** e criar **dois objetos** a partir dessa classe.

---

## 📌 Instruções

### 1️⃣ Criar uma Classe

O aluno deverá:

* Criar uma classe com nome significativo (ex: `Produto`, `Carro`, `Aluno`, `ContaBancaria`, etc).
* Definir:

  * Pelo menos **3 atributos**
  * Pelo menos **2 método**
* Utilizar o método `__init__` para inicializar os atributos.

---

### 2️⃣ Criar Dois Objetos

* Instanciar **dois objetos diferentes** da classe criada.
* Passar valores diferentes para os atributos.
* Exibir informações dos objetos utilizando `print()` ou chamando um método da classe.

---

### 3️⃣ Requisitos Obrigatórios

✅ Utilizar `class`
✅ Utilizar `__init__`
✅ Criar dois objetos
✅ Executar o código demonstrando o funcionamento
✅ Código deve rodar sem erros
