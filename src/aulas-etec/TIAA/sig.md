# ATIVIDADE PRÁTICA – DESENVOLVENDO UM SIG NO EXCEL

## Objetivo

O aluno deverá:

* Organizar dados operacionais
* Criar indicadores gerenciais
* Construir gráficos
* Simular um mini Sistema de Informação Gerencial
* Tomar decisões estratégicas com base nos dados

---

# CENÁRIO DA EMPRESA

Empresa fictícia: **Comercial Alpha**

Ramo: Loja de eletrônicos
Porte: Pequena empresa

---

# PARTE 1 – Base de Dados (Operacional)

Os alunos devem criar uma planilha chamada:

## 📌 ABA 1: BASE_DE_DADOS

Inserir no mínimo 30 registros com as colunas:

| Data | Produto | Vendedor | Quantidade | Preço Unitário | Custo Unitário |

Produtos sugeridos:

* Notebook
* Smartphone
* Impressora
* Monitor
* Teclado

Vendedores:

* Ana
* Carlos
* Juliana
* Marcos

---

# PARTE 2 – Cálculos (Transformando dado em informação)

Adicionar colunas:

* Receita = Quantidade x Preço
* Custo Total = Quantidade x Custo
* Lucro = Receita - Custo Total
* Margem (%) = Lucro / Receita

Aqui o aluno já começa a estruturar o SIG.

---

# PARTE 3 – Indicadores Gerenciais

Criar uma nova aba chamada:

## 📌 ABA 2: INDICADORES

Calcular:

1️⃣ Faturamento total
2️⃣ Lucro total
3️⃣ Margem média
4️⃣ Produto mais vendido
5️⃣ Vendedor com maior faturamento
6️⃣ Ticket médio

(Usar SOMA, MÉDIA, PROCV ou Tabela Dinâmica)

---

# PARTE 4 – Dashboard (Simulação de SIG)

Criar uma terceira aba:

## 📌 ABA 3: DASHBOARD

Inserir:

* Gráfico de vendas por produto
* Gráfico de lucro por vendedor
* Indicador de margem geral
* Indicador de faturamento total

Não precisa ser complexo — o objetivo é visualizar a informação.

---

# PARTE 5 – Tomada de Decisão

Responder no final da planilha:

1. Qual produto é mais rentável?
2. Qual produto vende muito mas lucra pouco?
3. Qual vendedor tem melhor desempenho?
4. Se você fosse o gestor, quais 3 decisões tomaria?

---
