# Principais Tags do HTML


## Estrutura Básica

`<html>`: Define o início e o fim de um documento HTML.

`<head>`: Contém metadados, como título, links para CSS e scripts.

`<title>`: Define o título exibido na aba do navegador.

`<body>`: Abriga todo o conteúdo visível da página.

Tags de Texto

`<h1>` até `<h6>`: Representam cabeçalhos, sendo `<h1>` o mais importante.

`<p>`: Define parágrafos.

`<b>` e `<strong>`: Destacam texto em negrito.

`<i>` e `<em>`: Destacam texto em itálico.

## Links e Imagens

`<a>`: Cria hiperlinks. O atributo href define o destino do link.

`<img>`: Insere imagens. O atributo src especifica o caminho da imagem e alt fornece texto alternativo.

## Listas

`<ul>`: Cria listas não ordenadas (com marcadores).

`<ol>`: Cria listas ordenadas (numeradas).

`<li>`: Define itens dentro de listas.

## Tabelas

`<table>`: Cria tabelas.

`<tr>`: Define uma linha na tabela.

`<td>`: Define uma célula de dados.

`<th>`: Define uma célula de cabeçalho.

## Formulários

`<form>`: Cria um formulário.

`<input>`: Define campos de entrada de dados.

`<button>`: Cria botões.

`<label>`: Associa rótulos a campos de entrada.

`<textarea>`: Cria áreas de texto maiores.

## Estrutura Semântica

`<header>`: Define o cabeçalho da página ou seção.

`<footer>`: Define o rodapé.

`<section>`: Agrupa conteúdo relacionado.

`<article>`: Representa um conteúdo independente, como um artigo.

`<aside>`: Define conteúdo complementar, como barras laterais.

`<nav>`: Cria menus de navegação.

## Outras Tags Úteis

`<div>`: Agrupa elementos em bloco para estilização ou scripts.

`<span>`: Agrupa elementos em linha para estilização.

`<br>`: Insere uma quebra de linha.

`<hr>`: Insere uma linha horizontal.
